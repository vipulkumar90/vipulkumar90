### 🛠️ 開発したもの

**リハビリテーション進捗可視化アプリケーション**

患者がリハビリテーションの進捗を視覚的に理解できるよう設計された、セラピスト主導型のヘルスケアアプリケーション。

このプロトタイプでは、リハビリテーションを日本国内の旅として表現し、リハビリテーションのマイルストーンを達成することで、患者が**北海道 → 東京**へと進んでいく仕組みを採用しています。

### 🔄 アイデアからプロトタイプへ

**🌸 初期コンセプト：日本庭園**

リハビリテーションのマイルストーンを達成するにつれて、庭にさまざまな要素が追加され、徐々に豊かになっていくことで進捗を表現しました。

⬇️ **ユーザーバリデーション**

視覚的なアプローチは好意的に受け止められましたが、ユーザーにとって「その先にどこへ向かっているのか」が必ずしも明確ではありませんでした。

⬇️ **デザインの改善**

**🗾 現在のコンセプト：日本の旅**

庭園というメタファーを、日本国内を旅するというメタファーへ変更し、**進捗と方向性**の両方を伝えられるようにしました。
