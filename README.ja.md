## 👨‍💻 自己紹介

現在、**九州工業大学大学院** 人間知能システム工学専攻の修士課程に在籍しています。

大学院進学前は**3年以上**エンタープライズ向けソフトウェア開発に携わり、現在はその経験を活かしながら、**機械学習**や**ヒューマンアクティビティ認識（HAR）**、**大規模言語モデル（LLM）**を活用したヘルスケアAIの研究に取り組んでいます。

研究だけでなく、実運用を意識した拡張性・保守性の高いソフトウェア開発も大切にしています。

## 🚀 主なプロジェクト

| プロジェクト | 概要 |
|--------------|------|
| 🧠 **Human Activity Recognition** | 2次元姿勢推定を用いた行動認識の研究。特徴量設計とLOSO評価による汎化性能の向上を目指しています。 |
| 🎧 **CareSoundAI** | 環境音認識とローカルLLMを組み合わせた、高齢者見守り支援Androidアプリ。 |
| 💼 **Job Alert** | 日本の求人サイトを自動巡回し、新着求人をDiscordへ通知するPythonアプリケーション。 |
| 🐄 **Ushi Facts** | GitHub Actionsを利用してAIに関する日英バイリンガル豆知識をDiscordへ自動投稿するプロジェクト。 |
